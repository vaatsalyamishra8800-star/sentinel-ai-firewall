Enterprise Security & Architecture Highlights
⚡ How fast is Sentinel's inspection engine?
Core regex detection, Unicode de-cloaking, and Shannon entropy evaluate payloads in under 0.5ms locally (average ~0.25ms). In local HTTP loopback, total turnaround is typically < 5ms. Network transit over public cloud (Render) depends on host routing.
🪤 What is HoneyPrompt Deception Technology?
HoneyPrompt is Sentinel's term for cryptographic canary tokens—an established security technique. Sentinel injects unique decoy strings into system prompts. If leaked in model output, Sentinel detects the breach and quarantines the agent.
🛡️ How does Tool RBAC protect multi-agent swarms?
Autonomous agents often call tools like SQL databases or refund APIs. Sentinel intercepts each function invocation, verifies caller trust & role permissions, and strips sensitive parameters before execution.
📜 How is Sentinel designed for regulatory frameworks?
Sentinel implements technical controls aligned with major regulatory guidance: SHA-256 chained audit logs for traceability (EU AI Act Art. 15 & SOC 2), automated Luhn payment card masking (aligned with PCI-DSS guidance), and regex/checksum PII redaction (aligned with HIPAA/GDPR privacy rules). Note: this represents architectural alignment, not an external audit certification.
